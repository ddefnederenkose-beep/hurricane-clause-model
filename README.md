# Hurricane-clause Monte Carlo debt model

Simulation model for the Bocconi 30443 Economic Evidence Brief: do sovereign hurricane clauses create fiscal space, or are they too limited when the problem is solvency rather than liquidity?

## Run it
```bash
python3 -m venv .venv && .venv/bin/pip install numpy pandas matplotlib pyyaml pytest
.venv/bin/python -m pytest -q          # all tests must pass
.venv/bin/python run_all.py            # ~45 s: tables -> outputs/tables, figures -> outputs/figures
```
`run_all.py` prints (a) the list of PLACEHOLDER_VERIFY parameters and (b) summary tables for every experiment. Options: `--seed N`, `--no-figures`.

## Live demo (for the video)
```bash
.venv/bin/pip install streamlit
.venv/bin/streamlit run app.py
```
Sidebar sliders: lambda, b0, s, K, repayment years (`defer_repay_years`), D_trig, plus Grenada-style / Barbados-style presets. Dragging repayment years below M flips the clause from helpful to harmful. The app imports `src/` and `config/`; it contains no model logic of its own.

## Layout
- `config/` calibration.yaml (every value has value / source / status / meaning), scenarios.yaml, designs.yaml (Grenada-style, Barbados-style clauses)
- `src/` hurricanes, economy, debt, regimes, simulate, metrics, experiments, plots, grenada (anchor function), docs_gen
- `tests/` pytest suite (accounting, CRN, reproducibility, trigger logic, trigger cap, units, experiment identities)
- `app.py` Streamlit demo
- `docs/` METHODS.md (appendix note; its parameter table is regenerated by run_all), DECISIONS.md, AI_LOG.md (template)

## Entering your own numbers
Edit the YAML files: set `value`, fill `source`, change `status` to `VERIFIED`. The Grenada anchor is the function `grenada_relief(deferred_payments, schedule, rate)` in `src/grenada.py`: call it with the actual post-Beryl deferral figures (none are entered in the code).

## Determinism
One seed, one set of hurricane draws shared by all regimes, model versions, designs and grid cells. Deterministic hits can be injected with `simulate(..., forced_hits={year: damage})`.
